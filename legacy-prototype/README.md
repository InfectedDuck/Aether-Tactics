# Legacy Static Prototype (Archived)

This folder holds the original single-page `index.html` / `app.js` / `styles.css` prototype,
plus its `assets/` and `factions.json` reference data.

It is **not** the deployed product. The active game is:

- Frontend: `../frontend/` (React + Vite, deployed to Vercel, `/menu`)
- Backend: `../backend/` (FastAPI on Render)

Kept here for reference only so the repo root stays clean and navigation work
in Phase 1 is not confused by two competing apps.
